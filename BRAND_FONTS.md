# Humm. font system

- Logo placeholder, display and headings: **Lexend Deca**
- Navigation, prices, labels and editorial details: **Space Mono**
- Product specifications and technical copy: **Source Code Variable / Source Code Pro**
- Playful stickers, marquee and occasional accents only: **Arcade Among 1**
- Interface controls and fallback: **Arial**

`Arcade Among 1` is self-hosted from `public/fonts/arcade-among-1.ttf`. It is not the Humm. logo font and must not be used for the wordmark. The logo shown in the brand reference is a separate custom graphic asset; until that asset is supplied, the website uses a neutral Lexend Deca wordmark placeholder.
